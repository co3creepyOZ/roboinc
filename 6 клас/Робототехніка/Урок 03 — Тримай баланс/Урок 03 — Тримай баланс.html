02 / Прилад і датчик · 3 хв

Від бульбашки до електроніки

Що таке ватерпас?

Ватерпас, або рівень, — прилад для перевірки горизонтального положення та невеликих нахилів. Його використовують під час вирівнювання конструкцій.

У бульбашковому рівні положення бульбашки відносно міток показує нахил. В електронному прототипі замість бульбашки використаємо датчик і світлодіодний дисплей.

Акселерометр micro:bit

Акселерометр вимірює прискорення за трьома осями. Коли плата нерухома, її показники змінюються залежно від нахилу відносно земного тяжіння. Під час руху вони також реагують на прискорення руху.

X

Напрямок ліворуч–праворуч. Основна вісь цього уроку.

Y

Напрямок вперед–назад. Додамо в складнішому варіанті.

Z

Напрямок перпендикулярно площині плати.

Що означає «прискорення (мг)»?

У блоці acceleration (mg) одиниця mg означає тисячну частину g — прискорення вільного падіння. Це не міліграми й не градуси.

Коли плата лежить нерухомо, дисплеєм угору, показники X та Y близькі до нуля. Не очікуй, що всі три осі одночасно покажуть нуль.

Для перевірки нахилу поклади плату на поверхню та дочекайся спокійного показника. Однієї осі X недостатньо для перевірки нахилу в усіх напрямках.

03 / Правило програми · 4 хв

Три можливі результати

У моделі домовимося: від’ємне X показуємо стрілкою ←, додатне — →. Стрілки позначають напрямок показника, а не команду, куди перемістити плату. На реальній платі перевір відповідність рухом у вибраній орієнтації.

Варіант 1: точний нуль

ЯКЩО X < 0 → ←
ІНАКШЕ ЯКЩО X > 0 → →
ІНАКШЕ → ✓

Галочка з’являється тільки при X = 0. Значення −1 та +1 вже дають різні стрілки.

Варіант 2: із допуском

Допуск — невеликий проміжок значень, який у нашій програмі вважаємо близьким до рівного положення. Оберемо навчальне значення 50 mg.

ЯКЩО X < −50 → ←
ІНАКШЕ ЯКЩО X > 50 → →
ІНАКШЕ → ✓

Галочка відповідає −50 ≤ X ≤ 50, включно з межами. Це умовний допуск прототипу, а не точність професійного рівня.

Позначення напрямків

L — left, ліворуч; R — right, праворуч; U — up, угору; D — down, униз. Стрілку можна намалювати блоком show leds або обрати відповідну готову іконку.

Для поточного показника використовуй змінну X. Зчитування й розгалуження мають повторюватися у блоці «постійно».

Передбач результат

X = −50, допуск 50. Що покаже програма?

04 / Майстерня · 5 хв

Утримай показник у межах

Повзунок задає навчальний показник X. Сторінка не зчитує датчики комп’ютера та не вимірює кут.

X, mgДопускСигнал

План досліду

  1. У режимі точного нуля перевір −1, 0 і 1.
  2. У режимі ±50 перевір −51, −50, 50 та 51. Запиши результати.
  3. Порівняй обидва режими при −1 та 1. Чому допуск робить індикатор спокійнішим?

Збери в MakeCode · додаткові 5–10 хв
  1. Створи проєкт «Тримай баланс» та змінну X.
  2. У «постійно» задай X = acceleration (mg), вісь x.
  3. Додай «якщо X < −50», у гілку «то» — стрілку ліворуч.
  4. У «інакше» вклади друге повне розгалуження: якщо X > 50 — стрілка праворуч, інакше — галочка.
  5. Перевір межі у симуляторі. На реальній платі повільно нахиляй її та перевір відповідність напрямків.

Для варіанта точного нуля заміни −50 та 50 на 0. Для власних стрілок скористайся show leds. Контекстне меню відкривається правою кнопкою миші; Duplicate копіює блок, Add comment додає пояснення.

06 / Завершення · 1 хв

Баланс — це правило й перевірка

Акселерометр дає числові дані. Розгалуження обирає стрілку або галочку. Допуск дозволяє не реагувати на невеликі зміни біля нуля.

Додатково: дві осі

Створи змінну Y і зчитуй acceleration y. Для галочки вимагай одночасно −50 ≤ X ≤ 50 І −50 ≤ Y ≤ 50. Перевір: X = 0, Y = 100; X = 100, Y = 0; X = 0, Y = 0.

Якщо обидві осі поза межами, домовся про порядок показу стрілок або показуй їх по черзі. U та D можна використати для другої осі, перевіривши відповідність на платі.
