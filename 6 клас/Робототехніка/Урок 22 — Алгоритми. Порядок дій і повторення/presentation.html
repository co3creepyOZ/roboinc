Три проходження, потім вихід

Лічильник на схемі пояснює роботу блока repeat.

  1. A: i ← 0
  2. i < 3? Ні → чекати A; Так ↓
  3. Серце → пауза 300 мс
  4. Очистити → пауза 300 мс
  5. i ← i + 1 → повернутися до умови

11

Знайди блоки MakeCode

Довідка до практики · 1

Input / Вхідні дані

Коли натиснуто кнопку A / on button A pressed
Подія починає одну серію; під час перевірки дочекайся завершення перед наступним A.

Loops / Цикли

Повторити 3 рази / repeat 3 times
Вклади всі чотири дії всередину. Після трьох проходжень керування виходить із циклу.

Basic / Основні

Показати іконку / show icon
Обери серце. Стандартний показ уже містить затримку; тут не вимірюємо точний час серії.
