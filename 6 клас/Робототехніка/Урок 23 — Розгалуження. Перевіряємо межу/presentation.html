Знайди блоки MakeCode

Довідка до практики · 1

Basic / Основні

На початку / on start
Розмісти тут присвоєння t та одне повне якщо — інакше; запуск повторюй після зміни числа.

Variables / Змінні

Задати t значення / set t to; читання t
Створи t через Make a Variable. set записує число, овальний t читає його в порівнянні.

Logic / Логіка

Менше / <; менше або дорівнює / ≤
Уклади t зліва й 20 справа. Перевір саме знак, особливо при t = 20.
