05

Радіо-настрій: опис подій

Спочатку число, потім реакція іншого пристрою.

КОЛИ натиснуто A / B / A+B
    НАДІСЛАТИ відповідно 0 / 1 / 2
    ПОКАЗАТИ свій настрій

КОЛИ отримано число
    0 → усмішка; 1 → сум; 2 → здивування
    ІНШЕ число → екран без змін
06

Збери Радіо-настрій

Обидві плати отримують однакову програму.

  1. 01

    При запуску: група 23, очистити екран.

  2. 02

    Кнопки A, B, A+B: надіслати число й показати свій настрій.

  3. 03

    При отриманні числа: перевір 0, 1, 2.

  4. 04

    Інші числа залиш без дії.

11

Число й рядок: узгодь обидва боки

Тип надсилання визначає потрібну подію отримання.

Радіо / Radio

send number ↔ on received number
Для настроїв: 0, 1, 2.

Радіо / Radio

send string ↔ on received string
Для качки: DUCK.

Логіка / Logic

якщо; дорівнює
Перевір значення до показу малюнка.

12

Збери програму «Качка»

Створи окремий проєкт із тією самою групою.

  1. 01

    При запуску встанови групу 23.

  2. 02

    На струшування: очистити екран, надіслати рядок DUCK.

  3. 03

    При отриманні рядка: якщо дорівнює DUCK — показати Duck.

  4. 04

    Інший рядок не повинен змінювати екран.
