Знайди блоки MakeCode

Довідка до практики · 3

Світлодіоди → додаткові / LED → more

Встановити яскравість / set brightness
255 перед показом; далі 160, 80, 20. Відновлення перед кожним показом зберігає яскравий початок.

Основні / Basic

Показати світлодіоди / show leds
Збережи малюнок 25 LED. Блок уже має стандартний показ 400 мс.

Основні / Basic

Пауза (мс) / pause (ms)
100 мс після кожної сходинки. 500 мс лише в гілці дозволеного повторного надсилання.
