Світло за гучністю

01

Модель і фізичний пристрій

Матриця

25 світлодіодів, а не кімнатна лампа.

Звук

Показник 0–255 від мікрофона V2, не децибели.

Модель

Повзунок задає число, мікрофон телефону не використовується.

04

Нічник має пам’ять

lightOn

Зберігає true або false.

Верхній поріг

Від 80 увімкнути.

Нижній поріг

Нижче 40 вимкнути.

05

Два пороги та збереження стану

Вхід уже зчитано або обрано. Перша істинна гілка завершує вибір.

voice ≥ 80? → Так: lightOn ← true
Ні ↓ наступна перевірка
voice < 40? → Так: lightOn ← false
Ні ↓ наступна перевірка
Інакше: Стан без зміни
↓ Показати стан
06

Те саме 60, але різна історія

ПослідовністьСтан після останнього
Скинути →39→60Вимкнено
Потім 80→60Увімкнено
Потім 40→39Спершу ввімкнено, потім вимкнено
07

Збережи попередній стан

Опис словами, не код для вставлення.

зчитати voice
якщо voice ≥ 80
  lightOn ← true
інакше якщо voice < 40
  lightOn ← false
показати світло за lightOn
08

Чесне порівняння режимів

Базовий

Залежить лише від поточного числа.

Нічник

Залежить і від попереднього стану.

Скидання моделі

Задає 0 та вимикає світло.

09

Перевір дві різні програми

  1. 01

    Для базової: 126/127/128.

  2. 02

    Для нічника: 39→60→80→60→40→39.

  3. 03

    Поясни два результати при 60.

11

Знайди блоки MakeCode

Довідка до практики · 1

Input / Вхідні дані

Рівень звуку / sound level
Запиши показник 0–255 у voice. Для фізичного пристрою потрібна V2.

Basic / Основні

При запуску / on start
Для нічника задай lightOn = false один раз на початку.

Logic / Логіка

Істина / true; хиба / false
Значення логічної змінної lightOn: увімкнено або вимкнено.

12

Знайди блоки MakeCode

Довідка до практики · 2

Basic / Основні

Постійно / forever
Повторює зчитування датчика та перевірку умови.

Variables / Змінні

Задати … значення / set … to; значення змінної
Натисни «Створити змінну / Make a Variable». Блок set змінює значення, овальний блок із назвою читає його.

Logic / Логіка

Якщо…то…інакше / if…then…else
Обирає дію за умовою. Додай гілку «інакше» кнопкою + на блоці, якщо її немає.
