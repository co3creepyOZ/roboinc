MakeCode Python · 1/1

Частини однієї програми; з’єднай їх по порядку.

def on_forever():
    contact = input.pin_is_pressed(TouchPin.P1)
    if contact:
        basic.show_icon(IconNames.YES)
    else:
        basic.show_icon(IconNames.NO)
    basic.pause(100)

basic.forever(on_forever)

Гортай код убік, щоб прочитати довгі рядки.
