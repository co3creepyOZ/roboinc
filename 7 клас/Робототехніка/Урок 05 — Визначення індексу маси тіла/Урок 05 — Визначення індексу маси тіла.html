01 / Знайомство

Проєкт «Визначення індексу маси тіла»

Тема уроку: формули, змінні, кнопки та перевірка даних.

Місія · 15–20 хвилин

Навчи micro:bit обчислювати за формулою, а себе — перевіряти одиниці вимірювання й відповіді ШІ. Теорія та дослідження — 5 хв, майстерня — 8–10 хв, квіз і висновок — 4–5 хв. Додаткові завдання виконуй за бажанням.

Працюємо лише з вигаданими тестовими даними дорослих. Не потрібно зважуватися, порівнювати тіла чи вводити дані однокласників. Це урок програмування, а не оцінювання здоров’я.

Спочатку припусти

У формулі потрібні метри. Що зробити зі значенням 180 см?

02 / Теорія

Формула має свої правила

Що таке ІМТ?

Індекс маси тіла (ІМТ, англійською BMI) — показник співвідношення маси та зросту. Формула: I = m / h², де m — маса в кілограмах, h — зріст у метрах. Одиниця результату — кг/м².

Для вигаданого прикладу m = 72 кг, h = 1,80 м: 72 / (1,8 × 1,8) ≈ 22,22. Квадрат числа — це множення числа на себе.

Що зберігають змінні?

Height = 180

Зріст у сантиметрах.

Massa = 0

Початкове значення лічильника маси. Його треба змінити.

BMI = 0

Місце для результату обчислення.

Додаткова змінна h = Height / 100 переводить сантиметри в метри. Тоді BMI = Massa / (h × h). Дужки об’єднують увесь знаменник.

Число не є діагнозом

ІМТ — лише один показник для попереднього оцінювання. Для дітей і підлітків його тлумачать з урахуванням віку та статі за спеціальними таблицями. Фіксовані дорослі межі не підходять для оцінювання школярів.

У цьому уроці діапазони потрібні лише для тренування умов на вигаданих даних. Не роби за ними висновків про своє здоров’я чи харчування.

03 / Дослідження

Прочитай алгоритм і знайди помилку

Події керують програмою

1. Послідовність дій

Почни з події «При запуску». Виконуй дії за стрілками згори донизу. Зістав кроки схеми з умовою завдання: Height = 180Massa = 0; BMI = 0; Кінець запуску.

2. Послідовність дій

Почни з події «Кнопка A». Виконуй дії за стрілками згори донизу. Зістав кроки схеми з умовою завдання: Massa = Massa + 1; Показати Massa; Кінець події.

3. Обробка кнопки B

Почни з події «Кнопка B». У ромбі обери гілку «Так» або «Ні» за результатом перевірки. Зістав кроки схеми з умовою завдання: Massa > 0?; Massa = Massa − 1; Показати Massa; Кінець події.

Обчислення за A+B

4. Перевірка даних перед обчисленням ІМТ

Почни з події «Кнопки A+B». У ромбі обери гілку «Так» або «Ні» за результатом перевірки. Зістав кроки схеми з умовою завдання: Height > 0І Massa > 0?; h = Height / 100BMI = Massa / (h × h); Показати ERR; Показати BMIта номер діапазону; Кінець перевірки.

Це карта подій, а не обов’язкова черга натискань: кнопки A та B можна натискати багато разів. Результат обчислюється за A+B.

Як читати блок-схему
  • Овал — початок або кінець.
  • Прямокутник — дія, обчислення або пауза.
  • Паралелограм — введення чи виведення даних.
  • Ромб — перевірка умови з виходами «Так» / «Ні».
  • Стрілки задають порядок; стрілка назад означає повторення.

Кінець обробки події не означає завершення всієї програми.

Де загубилися одиниці?

Програма обчислює 72 / (180 × 180). Чому результат неправильний для ІМТ?

Гілки без прогалин

Для навчального сортування дорослих тестових значень послідовно перевіряємо:

  1. якщо BMI < 18.5 → показати «1»;
  2. інакше якщо BMI < 25 → «2»;
  3. інакше якщо BMI < 30 → «3»;
  4. інакше → «4».

Рівно 25 потрапить у гілку 3, рівно 30 — у гілку 4. Порівнюємо неокруглене число; округлення потрібне лише для показу. Цифри — номери гілок, а не оцінка людини.

04 / Майстерня

Перевір, запрограмуй, поясни

Інтерактивне дослідження · тестовий стенд

Обери вигаданий приклад, спрогнозуй результат і натисни A+B. Поля дають змогу швидко підготувати тест без десятків натискань.

Натисни A+B. Початкове Massa = 0 ще не придатне для розрахунку.

Діапазон полів 0–250 — технічне обмеження стенда, не рекомендація. Після зміни даних попередній результат треба обчислити заново.

    Як читати цей код

    Читай код згори вниз. Рядки після # — коментарі для людини, вони не виконуються. Двокрапка : відкриває блок команд. Відступ у чотири пробіли показує, що команда належить умові, циклу чи функції. Коли відступ зменшується, вкладений блок закінчується.

    = записує значення, а == порівнює на рівність. У Python десяткову частину пишуть через крапку: 18.5. Слова й повідомлення беруть у лапки.

    Спочатку задаються Height і Massa. Функція calculate містить обчислення, on_a і on_b — зміну маси. Рядки input.on_button_pressed реєструють ці функції для A, B та A+B.

    Змінні, числа, рядки та логічні значення

    Height — число сантиметрів, Massa — число кілограмів. h — зріст у метрах, bmi — результат ділення, band — номер діапазону. Наприклад, 180 / 100 дає 1.8, а 72 / (1.8 × 1.8) — приблизно 22.22.

    "ERR" — рядок-повідомлення. str(band) перетворює число на текст для show_string. Умова Height <= 0 or Massa <= 0 дає логічне True або False. Номер band не є оцінкою здоров’я.

    Область видимості та global

    Height і Massa задані поза функціями — це спільні змінні програми. Функція calculate лише читає їх, тому global для читання не потрібне.

    on_a та on_b змінюють Massa. Саме тому в них написано global Massa: змінюємо спільну масу, а не створюємо локальну змінну з тією самою назвою. h, bmi і band потрібні тільки всередині calculate, тому залишаються локальними.

    Умови та захист від ділення на нуль

    Якщо хоча б одне значення недодатне, or робить умову істинною: показуємо ERR. Обчислення розташоване в else, тож за Height = 0 ділення не виконується.

    Далі неокруглений bmi порівнюється з 18.5, 25 і 30. Рівно 25 не менше за 25, тому потрапляє в band = 3. Округлюємо тільки показ числа.

    Чому тут немає while

    Це програма з подіями. MakeCode очікує кнопки та викликає зареєстровану функцію. Власний цикл для безперервного обчислення не потрібний: розрахунок запускає саме A+B.

    Перевір: A змінює Massa, B зменшує її до нуля, A+B обчислює. Використай вигадані дані 100 кг і 200 см: очікуємо 25 і номер 3.

    Приклад MakeCode Python · розгорни код
    # Дані лише вигаданого навчального прикладу
Height = 180
Massa = 0

def calculate():
    if Height <= 0 or Massa <= 0:
        basic.show_string("ERR")
    else:
        h = Height / 100
        bmi = Massa / (h * h)
        basic.show_string(str(round(bmi * 100) / 100))
        basic.pause(1000)
        # Порівнюємо неокруглене значення
        if bmi < 18.5:
            band = 1
        elif bmi < 25:
            band = 2
        elif bmi < 30:
            band = 3
        else:
            band = 4
        basic.show_string(str(band))

def on_a():
    global Massa
    Massa += 1
    basic.show_number(Massa)
input.on_button_pressed(Button.A, on_a)

def on_b():
    global Massa
    if Massa > 0:
        Massa -= 1
    basic.show_number(Massa)
input.on_button_pressed(Button.B, on_b)

# A+B викликає обчислення
input.on_button_pressed(Button.AB, calculate)

    Перевір роботу

    Задай початкові Massa = 72, Height = 180: очікуємо близько 22,22 та діапазон 2. 100/200 → 25 і 3; 120/200 → 30 і 4. Height = 0 → ERR.

    Для точного тесту підстав число замість зчитування датчика, потім поверни справжнє зчитування. Якщо потрібного датчика немає в симуляторі, виконай перевірку з підставленими значеннями або на відповідній платі.

    Відкрити MicroPython ↗. Відкрий Python Editor, заміни початковий код і запусти симулятор або перенеси на плату.

    Імпорт підключає команди micro:bit. while True повторює дії; sleep задає паузу в мілісекундах. Двокрапка й відступи визначають вкладені команди; = надає значення, == перевіряє рівність.

    Використовуй лише вигадані дані дорослих. Номери діапазонів не оцінюють здоров’я школярів. A додає 1 кг, B віднімає 1 до межі 0, A+B обчислює. У MicroPython утримай A, додай B і відпусти обидві; програма реагує після відпускання.

    Як читати цей код

    Читай код згори вниз. Рядки після # — коментарі для людини, вони не виконуються. Двокрапка : відкриває блок команд. Відступ у чотири пробіли показує, що команда належить умові, циклу чи функції. Коли відступ зменшується, вкладений блок закінчується.

    = записує значення, а == порівнює на рівність. У Python десяткову частину пишуть через крапку: 18.5. Слова й повідомлення беруть у лапки.

    Спочатку імпортуємо засоби micro:bit, задаємо Height і Massa та описуємо calculate. Потім цикл опитує кнопки. Тіло calculate виконується тільки під час виклику calculate().

    Змінні та типи даних

    Height і Massa — числа; h, bmi, band — проміжні числові значення. Рядок "ERR" є повідомленням. str(Massa) перетворює число на текст для прокручування.

    a та b — логічні значення: чи була натиснута відповідна кнопка. True означає «так», False — «ні». Це не числа маси й не символи кнопок.

    Область видимості змінних

    Height, Massa, a і b використовуються на верхньому рівні. Цикл while не створює власної області видимості, тому зміна Massa в циклі оновлює спільну змінну.

    calculate читає Height і Massa, але не змінює їх: global не потрібне. h, bmi і band створюються в calculate та потрібні лише там. Щоб змінювати спільну Massa з власної функції, довелося б оголосити global Massa.

    Розгалуження та порядок перевірок

    Спочатку if a and b перевіряє спільне натискання: обидва значення мають бути True. Лише після цього elif a та elif b обробляють одну кнопку.

    У calculate спочатку перевіряємо некоректні дані. Якщо Height або Massa не більші за нуль, показуємо ERR. Інакше обчислюємо bmi та обираємо номер діапазону.

    Два цикли: гра та відпускання кнопок

    Зовнішній while True постійно перевіряє кнопки. Внутрішній while триває, поки хоча б одна кнопка натиснута. Запис a = a or button_a.is_pressed() запам’ятовує натискання A: True зберігається до обробки цієї події.

    Після відпускання обох кнопок обирається одна дія. sleep(20) робить коротку паузу в опитуванні. Спробуй утримувати A: маса має змінитися один раз після відпускання, а не багато разів.

    Приклад MicroPython · розгорни код
    from microbit import display, button_a, button_b, sleep

# Дані лише вигаданого навчального прикладу
Height = 180
Massa = 0

def calculate():
    if Height <= 0 or Massa <= 0:
        display.scroll("ERR")
    else:
        h = Height / 100
        bmi = Massa / (h * h)
        display.scroll(str(round(bmi * 100) / 100))
        sleep(1000)
        # Порівнюємо неокруглене значення
        if bmi < 18.5:
            band = 1
        elif bmi < 25:
            band = 2
        elif bmi < 30:
            band = 3
        else:
            band = 4
        display.scroll(str(band))

while True:
    a = button_a.is_pressed()
    b = button_b.is_pressed()
    if a or b:
        # Чекаємо відпускання, запам’ятовуючи обидві кнопки
        while button_a.is_pressed() or button_b.is_pressed():
            a = a or button_a.is_pressed()
            b = b or button_b.is_pressed()
            sleep(20)
        if a and b:
            calculate()
        elif a:
            Massa += 1
            display.scroll(str(Massa))
        elif b:
            if Massa > 0:
                Massa -= 1
            display.scroll(str(Massa))
    sleep(20)
