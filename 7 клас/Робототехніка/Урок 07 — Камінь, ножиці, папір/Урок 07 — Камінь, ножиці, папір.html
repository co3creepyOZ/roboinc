1 / Знайомство

Камінь, ножиці, папір

Тема уроку

Гра «Камінь, ножиці, папір». Створи електронний вибір предмета за струшуванням і перевір три гілки програми.

18–20 хв: теорія — 4 хв, дослідження — 3 хв, один обраний варіант програмування — 8 хв, квіз і висновок — 3–5 хв. Інші редактори, радіо та розширення — додатково.

Передбач

Двічі поспіль випав камінь. Чи може випадковий вибір працювати правильно?

Безпечна робота

Струшуй плату обережно, тримай міцно, не натягуй кабель. Для короткого уроку достатньо моделі та редактора.

2 / Теорія

Від правил до програми

Три предмети — три правила

Камінь перемагає ножиці, ножиці — папір, папір — камінь. Однакові предмети дають нічию.

Домовимось: 1 — камінь, 2 — ножиці, 3 — папір. Одне струшування обирає одне число. Змінна зберігає його, а розгалуження показує один малюнок. Повторення результату можливе; три спроби не гарантують три різні предмети.

Проєкт має чотири етапи

  1. Підготовка: домовся про предмети та правила.
  2. Розробка: склади програму й перевір кожне значення.
  3. Презентація: покажи партнеру, як грати.
  4. Підсумок: назви одну помилку або покращення.

Базова програма на платі лише обирає предмет. Переможця визначають гравці. Сторінка нижче додатково допомагає перевіряти правила.

3 / Дослідження

Один вибір — одна гілка

Прочитай алгоритм

Струшування → вибрати число один раз → перевірити значення → показати предмет.

Блок-схема алгоритму

1. Струшування

Почни з події «Струшування». У ромбі обери гілку «Так» або «Ні» за результатом перевірки. Зістав кроки схеми з умовою завдання: number ← випадкове число; 1…3; number = 1?; Показати камінь; number = 2?; Показати ножиці.

Як читати блок-схему
  • Овал — початок або кінець.
  • Прямокутник — дія, обчислення або пауза.
  • Паралелограм — введення чи виведення даних.
  • Ромб — перевірка умови з виходами «Так» / «Ні».
  • Стрілки задають порядок; стрілка назад означає повторення.

Кінець обробки події не означає завершення всієї програми.

Алгоритм псевдомовою

Це опис кроків звичайними словами, а не готовий код для редактора. Відступи показують вкладені дії.

Прочитай приклад псевдомовою
КОЛИ струсили плату:
    number = випадкове число від 1 до 3
    ЯКЩО number = 1: показати камінь
    ІНАКШЕ ЯКЩО number = 2: показати ножиці
    ІНАКШЕ: показати папір

Простеж виконання: number = 1 → камінь; 2 → ножиці; 3 → папір. Число обирається один раз на струшування.

Робот: камінь, ножиці, папір

Відтвори розгалуження уроку. number = 1 → Камінь; number = 2 → Ножиці. Інакше → Папір.

Як працювати з грою · крок за кроком
  1. Прочитай правило уроку. Обери умову для кожної перевірки.
  2. Признач дію гілці «Так». «Ні» веде до наступної перевірки; після останньої — до «Інакше».
  3. Обери кінцеву дію «Інакше» та запусти робота.
  4. Простеж підсвічені кроки й результати тестів. Після помилки прочитай підказку, зміни налаштування та повтори.

Це один прохід розгалуження. Події, зчитування даних, паузи та повторення залишаються в програмі уроку; у грі налаштовуємо лише вибір дії.

Гра перевіряє наведені приклади, не читає датчики й не запускає реальне радіо. Зелений результат означає проходження цих тестів.

    4 / Майстерня

    Майстерня

    Інтерактивне дослідження

    Натисни «Струсити» або примусово обери 1, 2, 3 для перевірки кожної гілки. Тестовий вибір не випадковий.

    Ще немає вибору.

    MakeCode · блоки

    Відкрити MakeCode. Обери один із трьох способів реалізації. Очікування для всіх однакове: 1 → камінь, 2 → ножиці, 3 → папір.

    1. Створи змінну number. Додай подію «на струшування».
    2. Усередині події задай number = випадкове число від 1 до 3.
    3. Додай «якщо number = 1», «інакше якщо number = 2», «інакше».
    4. Покажи малюнки: заповнений квадрат 3×3 — камінь, хрестик — ножиці, рамка 5×5 — папір.
    5. Тимчасово підстав 1, 2, 3 замість випадкового числа, перевір малюнки й поверни випадковий вибір.
    1. З чого почати?

    Знайди подію струшування. Випадковий вибір має бути всередині неї, перед умовами.

    2. Які блоки допоможуть?

    Вхідні дані: на струшування. Змінні: number. Математика: вибрати випадково. Логіка: якщо/інакше, дорівнює. Основні: показати світлодіоди.

    3. Як перевірити?

    1 має показати квадрат, 2 — хрестик, 3 — рамку. Збережи одне число та порівнюй саме його у всіх умовах.

    MakeCode Python

    Відкрити редактор. Використай саме цей варіант коду: команди двох редакторів відрізняються.

    Завдання: запусти приклад, перевір значення 1, 2, 3; потім зміни тільки малюнок паперу й повтори перевірку.

    Показати приклад після власної спроби
    # Один випадковий вибір на одне струшування

    # 1 — камінь, 2 — ножиці, 3 — папір
    if number == 1:
        basic.show_leds("""
            . . . . .
            . # # # .
            . # # # .
            . # # # .
            . . . . .
            """)
    elif number == 2:

            # . . . #

    else:

            # . . . #

            # . . . #

input.on_gesture(Gesture.SHAKE, on_gesture_shake)
    1. Як читати код

    def описує дії після струшування. Останній рядок реєструє цю подію; тіло виконується при жесті.

    2. Змінна, типи й область видимості

    number — ціле число 1, 2 або 3. Порівняння number == 1 дає логічне значення True або False. number локальна всередині on_gesture_shake; global не потрібен, бо поза цією дією вона не використовується.

    3. Розгалуження, повторення та відступи

    if / elif / else обирає лише одну гілку. = надає значення, == порівнює. Відступи показують вкладеність. Окремий while тут не потрібен: редактор викликає обробник події.

    Перевірка: тимчасово підстав 1, 2 і 3 замість випадкового числа. Очікуй камінь, ножиці та папір відповідно. Потім поверни випадковий вибір.

    MicroPython

    Відкрити редактор. Використай саме цей варіант коду: команди двох редакторів відрізняються.

    Завдання: запусти приклад, перевір значення 1, 2, 3; потім зміни тільки малюнок паперу й повтори перевірку.

    Показати приклад після власної спроби
    from microbit import *
import random

# Постійно перевіряємо, чи було струшування
while True:
    if accelerometer.was_gesture("shake"):
        number = random.randint(1, 3)
        # Малюнки: камінь, ножиці, папір
        if number == 1:
            display.show(Image("00000:09990:09990:09990:00000"))
        elif number == 2:
            display.show(Image("90009:09090:00900:09090:90009"))
        else:
            display.show(Image("99999:90009:90009:90009:99999"))
    sleep(50)  # Пауза між перевірками жесту
    1. Як читати код

    Імпорти дають доступ до плати й випадкових чисел. while True повторює перевірку жесту. Лише після струшування вибирається число.

    2. Змінна, типи й область видимості

    number — ціле число 1, 2 або 3. Порівняння number == 1 дає логічне значення True або False. number створюється на рівні програми після першого жесту. if і while не створюють окремої області видимості. Рядок "shake" означає назву жесту; рядки з цифрами описують малюнок.

    3. Розгалуження, повторення та відступи

    if / elif / else обирає лише одну гілку. = надає значення, == порівнює. Відступи показують вкладеність. sleep(50) розміщено в циклі, але поза if: пауза є навіть коли струшування не було.

    Перевірка: тимчасово підстав 1, 2 і 3 замість випадкового числа. Очікуй камінь, ножиці та папір відповідно. Потім поверни випадковий вибір.

    3. Як перевірити?

    Перевір дев’ять пар предметів. До вибору обох гравців бал не нараховується; повторне повідомлення не зараховує раунд удруге.

    Додатково: коротке ТЗ

    Мета: зробити папір упізнаваним. Поведінка: зміни тільки малюнок для 3. Засоби: готова програма. Перевірки: 3 показує новий малюнок; 1 і 2 лишаються без змін.
