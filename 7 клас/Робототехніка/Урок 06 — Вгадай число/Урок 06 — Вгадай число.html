01 / Знайомство

Проєкт «Вгадай число»

Тема уроку: випадкові числа, змінні, події та розгалуження.

Твоя місія · 15–20 хвилин

Створи гру: micro:bit загадує число від 0 до 10 включно, а гравець знаходить його за підказками. Навчися читати знаки порівняння й перевіряти логіку програми.

Пояснення й дослідження — 5 хв, гра та програмування — 8–10 хв, перевірка з ШІ, квіз і висновок — близько 5 хв. Додаткові рівні виконуй за бажанням. Можна працювати без плати у симуляторі.

Спочатку припусти

Скільки різних цілих чисел можна загадати від 0 до 10 включно?

02 / Теорія

Що зберігає гра?

Дві змінні — різні ролі

number

Таємне випадкове ціле число від 0 до 10. Створюється один раз на початку раунду.

відповідь

Поточне припущення гравця. Спочатку 0; змінюється кнопками.

Не обирай новий number під час кожної перевірки: тоді підказки стосуватимуться різних чисел. Новий раунд може випадково загадати те саме число — це нормально.

Події кнопок

  • A збільшує відповідь на 1.
  • B зменшує відповідь на 1.
  • A+B порівнює number і відповідь.

Додамо обмеження: відповідь не виходить за 0…10. Натискання A або B змінює припущення; спробою вважаємо лише A+B.

Як читати підказку?

number > відповідь: таємне число більше за твоє — збільш припущення.

number < відповідь: таємне число менше за твоє — зменш припущення.

number = відповідь: «You win!» — «Ти переміг / перемогла!».

Знак описує таємне число відносно відповіді, а не навпаки.

03 / Дослідження

Звужуй коло можливих чисел

Приклад міркування

Почни з 5. Якщо number > 5, залишаються 6, 7, 8, 9, 10. Спробуй 8. Якщо number < 8, залишаються 6 і 7.

Перевірка числа поблизу середини діапазону відкидає приблизно половину варіантів. Для 11 чисел достатньо щонайбільше 4 перевірок, якщо щоразу вдало ділити решту варіантів навпіл.

Повне розгалуження

1. Початок: натиснуто A+B

Почни з події «Початок: натиснуто A+B». У ромбі обери гілку «Так» або «Ні» за результатом перевірки. Зістав кроки схеми з умовою завдання: number > відповідь?; number < відповідь?; Показати «>»; Показати «<»; Показати; «You win!».

Числа або більші, або менші, або рівні. Тому остання гілка означає рівність. На слайді можна використати три окремі перевірки; тут об’єднуємо їх у повне розгалуження.

Як читати блок-схему
  • Овал — початок або кінець.
  • Прямокутник — дія, обчислення або пауза.
  • Паралелограм — введення чи виведення даних.
  • Ромб — перевірка умови з виходами «Так» / «Ні».
  • Стрілки задають порядок; стрілка назад означає повторення.

Кінець обробки події не означає завершення всієї програми.

Алгоритм псевдомовою

Це опис кроків звичайними словами, а не готовий код для редактора. Відступи показують вкладені дії.

Прочитай приклад псевдомовою
КОЛИ натиснуто A+B
    ЯКЩО number > відповідь ТО
        ПОКАЗАТИ «>»
    ІНАКШЕ ЯКЩО number < відповідь ТО
        ПОКАЗАТИ «<»
    ІНАКШЕ
        ПОКАЗАТИ «You win!»
    КІНЕЦЬ ЯКЩО
КІНЕЦЬ ПЕРЕВІРКИ

Прочитай разом зі схемою: кожне «ЯКЩО» відповідає ромбу, «ПОКАЗАТИ» — паралелограму. Відступи допомагають побачити, яка дія належить до якої гілки.

Простеж виконання: number = 7, відповідь = 5. Перша умова істинна, тому показуємо «>». Решту гілок пропускаємо й завершуємо перевірку.

Передбач підказку

Для тесту number = 7, відповідь = 5. Що покаже програма?

Про цю гру

Налаштуй алгоритм на схемі та перевір усі тестові показники. Гра є навчальною моделлю: вона не читає датчики плати.

04 / Майстерня

Зіграй і створи власну гру

Інтерактивне дослідження

Число вже загадано. Змінюй відповідь кнопками A та B, а A+B використай для перевірки. Звертай увагу на історію підказок.

Відповідь: 0

Number? Обери відповідь і перевір її.

Перевірок: 0

    Тестовий режим · відоме число

    Використай після гри, щоб перевірити всі гілки й крайні значення.

    Створи програму в редакторі

    «Вгадай число» в MakeCode

    Відкрити MakeCode ↗
    1. Створи змінні number та відповідь. У «при запуску» задай number = вибрати випадково від 0 до 10, покажи рядок «Number?», задай відповідь = 0 та покажи її.
    2. Для кнопки A: якщо відповідь < 10, зміни її на 1; після умови покажи відповідь.
    3. Для кнопки B: якщо відповідь > 0, зміни її на −1; після умови покажи відповідь.
    4. Для A+B створи «якщо / інакше якщо / інакше». Якщо number > відповідь — покажи рядок «>». Інакше якщо number < відповідь — «<». Інакше — «You win!».
    5. Перевір усі три гілки: тимчасово задай number = 7 і порівняй відповіді 5, 9 та 7. Очікуємо >, < і перемогу.
    6. Окремо задай number = 0 та 10. Перевір крайні значення і те, що B не зменшує відповідь нижче 0, а A не збільшує понад 10. Поверни випадковий вибір перед грою.

    У базовому проєкті нове число обирається після перезапуску. Браузерна гра додатково має «Новий раунд» та блокує перевірки після перемоги. Щоб повторити це на платі, додай змінну «граТриває»: true на старті, false після перемоги; обробляй кнопки лише коли вона true.

    Контекстне меню відкривається правою кнопкою миші. Duplicate / Дублювати копіює блок; не забудь змінити знак порівняння в копії.

    Підказка: як виконати завдання. Спочатку спробуй самостійно. Відкривай лише потрібний крок; підказки не знижують оцінку.

    1. З чого почати?

    Створи змінні number та відповідь. У «при запуску» задай number = вибрати випадково від 0 до 10, покажи рядок «Number?», задай відповідь = 0 та покажи її.

    2. Які блоки допоможуть?

    Основні / Basic — виведення; Вхідні дані / Input — датчик або кнопка; Змінні / Variables — збереження значення; Логіка / Logic — умови.

    3. Як перевірити?

    Окремо задай number = 0 та 10. Перевір крайні значення і те, що B не зменшує відповідь нижче 0, а A не збільшує понад 10. Поверни випадковий вибір перед грою. Якщо результат інший, перевір подію запуску та порядок блоків усередині події. Зміни одну причину й повтори тест.

    Створи програму в редакторі

    Python у середовищі MakeCode

    Цей варіант призначений саме для MakeCode. Створи проєкт і вибери мову Python у верхньому меню редактора. Заміни початковий код наведеним прикладом.

    Не змішуй два середовища: у MicroPython використовуємо from microbit import ... та display; у MakeCode — basic, input і Button. Тут імпорти з MicroPython не потрібні. MakeCode сам викликає функцію, коли відбувається зареєстрована подія.

    Підказки до цього прикладу

    Фіолетовий — ключові словаЗелений — рядкиПомаранчевий — числаСиній — функції

    Розгорни потрібне пояснення. Приклади нижче стосуються саме цієї програми.

    Як читати цей код

    Читай код згори вниз. Рядки після # — коментарі для людини, вони не виконуються. Двокрапка : відкриває блок команд. Відступ у чотири пробіли показує, що команда належить умові, циклу чи функції. Коли відступ зменшується, вкладений блок закінчується.

    = записує значення, а == порівнює на рівність. У Python десяткову частину пишуть через крапку: 18.5. Слова й повідомлення беруть у лапки.

    На початку один раз обирається number, answer отримує 0, playing — True. Далі описуються функції трьох кнопок та їхні події. Завершують початковий запуск повідомлення Number? і показ answer.

    Змінні та три типи даних

    Змінна — ім’я, за яким програма зберігає й читає поточне значення. Наприклад, після answer = 0 змінна answer містить 0, а після answer = answer + 1 — 1. Спочатку обчислюється права частина, потім результат записується зліва.

    У цій грі number і answer — цілі числа. playing — логічне значення: True дозволяє гру, False блокує наступні дії після перемоги. "Number?", ">" та "You win!" — рядки.

    Порівняння чисел повертає True або False. answer += 1 — короткий запис answer = answer + 1. Число 7 та рядок "7" — різні типи значень.

    Область видимості та global

    number, answer і playing задані поза функціями й зберігають стан гри. У функціях A та B є global answer, бо ці функції змінюють спільну відповідь. У функції A+B є global playing, бо після перемоги вона записує False.

    Для читання number або перевірки playing оголошення global не потрібне. Якщо додаєш лічильник attempts і змінюєш його у функції A+B, додай його до global саме там.

    Умови: межі та підказки

    Зовнішнє if playing дозволяє дії лише під час гри. Додаткові умови answer < 10 і answer > 0 не дають вийти за межі.

    За number = 7 і answer = 5 перша гілка порівняння показує >. За answer = 9 виконується elif та показує <. За answer = 7 обидві умови хибні, тож else завершує гру.

    Події замість циклу опитування

    У цьому варіанті немає власного while. MakeCode сам очікує натискання й викликає потрібну функцію через input.on_button_pressed. Для A+B є окрема подія Button.AB.

    number не переобирається під час перевірок, бо randint стоїть лише на початку. Перезапуск створює новий раунд; він може випадково загадати те саме число.

    Приклад Python для MakeCode · розгорни код
    # Початкові значення для одного раунду
number = randint(0, 10)
answer = 0
playing = True

# Кнопка A збільшує відповідь у межах 0–10
def on_button_pressed_a():
    global answer
    if playing:
        if answer < 10:
            answer += 1
        basic.show_number(answer)
input.on_button_pressed(Button.A, on_button_pressed_a)

# Кнопка B зменшує відповідь у межах 0–10
def on_button_pressed_b():
    global answer
    if playing:
        if answer > 0:
            answer -= 1
        basic.show_number(answer)
input.on_button_pressed(Button.B, on_button_pressed_b)

# A+B перевіряє відповідь, не змінюючи таємного числа
def on_button_pressed_ab():
    global playing
    if playing:
        if number > answer:
            basic.show_string(">")
        elif number < answer:
            basic.show_string("<")
        else:
            playing = False
            basic.show_string("You win!")
input.on_button_pressed(Button.AB, on_button_pressed_ab)

# Початкове повідомлення; новий раунд — після перезапуску
basic.show_string("Number?")
basic.show_number(answer)

    def оголошує функцію. global answer дозволяє змінювати спільну змінну гри всередині функції; global playing — завершити раунд. input.on_button_pressed(...) пов’язує кнопку з функцією. Для A+B є окрема подія Button.AB, тому цикл очікування відпускання кнопок із прикладу MicroPython тут не потрібний.

    Змінні та три типи даних

    Змінна — ім’я, за яким програма зберігає й читає поточне значення. Наприклад, після answer = 0 змінна answer містить 0, а після answer = answer + 1 — 1. Спочатку обчислюється права частина, потім результат записується зліва.

    number та answer — цілі числа. playing, a і b — логічні значення True/False. Повідомлення в лапках — рядки. str(answer) перетворює число на рядок для display.show; 10 може прокручуватися, бо має два символи.

    Область видимості змінних

    У прикладі немає власних функцій: змінні задаються на верхньому рівні. Блоки while та if не створюють нової області видимості. Тому playing = False у гілці перемоги змінює ту саму playing, яку перевіряє зовнішній цикл.

    global тут не потрібне. Воно знадобилося б, якби власна функція змінювала змінну, створену поза нею. a та b заново зчитуються на початку кожного проходу зовнішнього циклу.

    Умови: and, or та три результати

    a or b — натиснута хоча б одна кнопка; a and b — зафіксовано обидві. Перевірка обох стоїть перед перевірками окремих кнопок.

    Усередині A+B порівнюємо незмінне number з answer. if обирає >, elif — <, else — перемогу. Межі 0 і 10 захищені окремими умовами в гілках A та B.

    Як працюють вкладені цикли

    while playing повторюється, поки playing дорівнює True. Внутрішній while чекає відпускання кнопок. a і b запам’ятовують, які кнопки були натиснуті під час утримання, тому одна дія виконується після відпускання.

    Після перемоги playing стає False. Поточний прохід доходить до кінця, а новий уже не починається. Для нового раунду перезапусти програму. Утримання A має додати лише 1, а A+B — лише перевірити відповідь.

    Приклад MicroPython · розгорни код
    from microbit import display, button_a, button_b, sleep
from random import randint

number = randint(0, 10)
answer = 0
playing = True
display.scroll("Number?")
display.show(str(answer))

while playing:
    a = button_a.is_pressed()
    b = button_b.is_pressed()

    if a or b:
        # Чекаємо відпускання та запам’ятовуємо обидві кнопки.
        while button_a.is_pressed() or button_b.is_pressed():
            a = a or button_a.is_pressed()
            b = b or button_b.is_pressed()
            sleep(20)

        if a and b:
            if number > answer:
                display.show(">")
            elif number < answer:
                display.show("<")
            else:
                display.scroll("You win!")
                playing = False
        elif a:
            if answer < 10:
                answer = answer + 1
            display.show(str(answer))
        elif b:
            if answer > 0:
                answer = answer - 1
            display.show(str(answer))

    sleep(20)

    Керування: натисни й відпусти A для +1 або B для −1. Для перевірки утримуй A, додай B, потім відпусти обидві кнопки. Програма чекає відпускання й запам’ятовує кнопки: так A+B не змінює відповідь випадково. Після перемоги натисни Reset / перезапусти симулятор для нового раунду.
