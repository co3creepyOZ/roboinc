2 / Теорія

Перетворюємо час на відстань

Світло приходить раніше за звук

Світло поширюється набагато швидше за звук. На відстанях цього досліду час проходження світла нехтуємо, а затримку грому вважаємо часом проходження звуку.

У навчальній моделі беремо швидкість звуку 343 м/с — наближене значення для повітря близько 20 °C. Реальна швидкість залежить від умов; реакція людини теж додає похибку.

Формула та одиниці

Відстань = швидкість × час.

Годинник micro:bit повертає мілісекунди від запуску. Потрібна різниця двох показів: elapsed = кінець − start.

Метри = elapsed × 343 / 1000. Ділимо на 1000, щоб перетворити мілісекунди на секунди. Для кілометрів поділи метри ще на 1000.

Приклад: 3000 мс = 3 с; 3 × 343 = 1029 м = 1,029 км. У програмі відкидаємо дробову частину метра: це не робить вимірювання точнішим.

Змінні та стани

  • start, elapsed, distance — числа.
  • active — логічне значення: чи очікуємо B.
  • ready — чи готовий результат для A+B.
  • "?" — рядок для повідомлення про відсутній результат.

A встановлює active = True і ready = False. B обчислює результат лише коли active істинне. Після B: active = False, ready = True. Нове A починає новий дослід.

3 / Дослідження

Спочатку передбач, потім перевір

Обчисли подумки

A зафіксовано на 5000 мс, B — на 7000 мс. Яка відстань?

Три події — три окремі маршрути

На старті active і ready дорівнюють False. Стрілки всередині кожної схеми показують дії одного обробника.

1. Натиснуто A

Почни з події «Натиснуто A». Виконуй дії за стрілками згори донизу. Зістав кроки схеми з умовою завдання: start ← поточний час; active ← True; ready ←; False; Показати ромб; Кінець обробки.

2. Натиснуто B

Почни з події «Натиснуто B». У ромбі обери гілку «Так» або «Ні» за результатом перевірки. Зістав кроки схеми з умовою завдання: active = True?; elapsed ← час − start;; distance ← ціла частина; elapsed × 343 / 1000;; active ← False; ready ←; True; показати галочку.

3. Натиснуто A+B

Почни з події «Натиснуто A+B». У ромбі обери гілку «Так» або «Ні» за результатом перевірки. Зістав кроки схеми з умовою завдання: ready = True?; Показати distance у; метрах; Показати ?; Кінець обробки.

Як читати блок-схему
  • Овал — початок або кінець.
  • Прямокутник — дія, обчислення або пауза.
  • Паралелограм — введення чи виведення даних.
  • Ромб — перевірка умови з виходами «Так» / «Ні».
  • Стрілки задають порядок; стрілка назад означає повторення.

Кінець обробки події не означає завершення всієї програми.

Алгоритм псевдомовою

Це опис звичайними словами. ← означає присвоєння. Відступи відділяють дії всередині умови; події не виконуються самі по черзі.

Прочитай приклад псевдомовою
НА СТАРТІ: active ← НІ; ready ← НІ
КОЛИ натиснуто A:
    start ← поточний час у мс
    active ← ТАК; ready ← НІ
    ПОКАЗАТИ ромб
КОЛИ натиснуто B:
    ЯКЩО active ТО
        elapsed ← поточний час − start
        distance ← ціла частина (elapsed × 343 / 1000)
        active ← НІ; ready ← ТАК
        ПОКАЗАТИ галочку
    КІНЕЦЬ ЯКЩО
КОЛИ натиснуто A+B:
    ЯКЩО ready ТО ПОКАЗАТИ distance
    ІНАКШЕ ПОКАЗАТИ ?
    КІНЕЦЬ ЯКЩО

Простеж виконання: B до A нічого не обчислює; A+B показує ?. A на 5000 мс, B на 7000 мс: elapsed = 2000, distance = 686. Повторне B не змінює результат.

Про цю гру

Налаштуй алгоритм на схемі та перевір усі тестові показники. Гра є навчальною моделлю: вона не читає датчики плати.

4 / Майстерня

Вимірюй на безпечній моделі

Інтерактивне дослідження

Оберіть точний тестовий інтервал або режим секундоміра. Це модель натискань, вона не слухає мікрофон і не визначає справжню блискавку.

Немає результату.

У точному режимі B використовує інтервал, обраний перед A; чекати його не потрібно. У режимі секундоміра B фіксує фактично минулий час. Числовий результат моделі наведено поруч із матрицею; на платі він прокручується.

MakeCode · блоки

Завдання: A починає вимірювання, B завершує його, A+B показує метри. B без старту і повторне B ігноруються. Нове A скасовує готовність старого результату.

Відкрити MakeCode ↗

  1. Створи start, elapsed, distance, active, ready. На старті числа = 0, логічні змінні = false.
  2. У події A запиши «час роботи (мс)» у start, active = true, ready = false; покажи ромб.
  3. У події B додай «якщо active»: elapsed = час роботи − start, distance = округлення вниз (elapsed × 343 / 1000).
  4. У тій самій гілці B задай active = false, ready = true й покажи галочку.
  5. У A+B перевір ready: покажи distance, інакше рядок ?.

Спочатку спробуй самостійно. Відкривай лише потрібну підказку.

1. З чого почати?

Спочатку перевір лише A → B → A+B. Час роботи не скидається при A, тому зберігай його показ, а не намагайся обнулити годинник плати.

2. Які блоки допоможуть?

Три події кнопок, змінні, логічні true/false, «якщо…інакше», віднімання, множення, ділення та округлення вниз. Покази й назви наведені в довідці нижче.

3. Як перевірити?

Тимчасово задай elapsed = 1000, 3000, 5000 у гілці B: очікуй 343, 1029, 1715 м. Потім поверни різницю годинника. Перевір B до A та нове A після готового результату.

MakeCode Python

Завдання: запусти калькулятор у цьому редакторі. Перевір нормальний порядок і помилкові натискання. Потім зміни показ результату з метрів на кілометри.

Відкрити редактор ↗

Приклад програми
start = 0
elapsed = 0
distance = 0
active = False
ready = False

def on_a():
    global start, active, ready
    # Новий старт скасовує попередній результат
    start = input.running_time()
    active = True
    ready = False
    basic.show_icon(IconNames.DIAMOND)

def on_b():

    if active:

        distance = Math.floor(elapsed * 343 / 1000)
        active = False
        ready = True

def on_ab():

        basic.show_number(distance)
    else:

input.on_button_pressed(Button.B, on_b)
input.on_button_pressed(Button.AB, on_ab)

Спочатку спробуй самостійно. Відкривай лише потрібну підказку.

1. Як читати код і змінні?

Функції on_a та on_b змінюють спільні змінні, тому мають global. on_ab лише читає ready і distance — для читання global не потрібний. Глобальні змінні оголошено до запуску обробників.

elapsed = 3000
distance = Math.floor(elapsed * 343 / 1000)

3000 мс перетворюються на 1029 м. Не забувай ділити на 1000.

2. Типи, умови та повторення

Час і відстань — числа; active та ready — логічні значення; ? — рядок. if active: читає стан, active = False змінює його. Відступи визначають, що саме належить умові.

Події реєструються через input.on_button_pressed; явний цикл очікування не потрібний. Math.floor відкидає дробову частину додатної відстані. Не перенось ці команди в MicroPython.

3. Як перевірити?

У гілці B тимчасово підстав elapsed = 1000, 3000, 5000: очікуй 343, 1029, 1715. Віднови годинник. B до A не створює результату; A+B без готових даних показує ?; повторне B не перераховує відстань. Показ у км має бути 0,343; 1,029; 1,715.

Продовж дослідження

Коротке ТЗ «Метри та кілометри»

Мета: змінити одиниці без зміни вимірювання. Поведінка: A+B показує відстань у кілометрах і позначку km. Засоби: готовий проєкт, ділення та показ рядка/числа.

Перевірка: 1000 мс → 0,343 км; 5000 мс → 1,715 км. Не округлюй до цілого кілометра.

Підказка: як виконати ТЗ

Збережи distance у метрах. Лише під час показу використай distance / 1000. Для дробових чисел у коді використовуй крапку.

Автоматична зупинка за звуком · micro:bit V2

A залишається стартом; гучний звук замінює B. Після першого звуку заверши вимірювання, наступні звуки ігноруй до нового A. Випробовуй лише умовним звуком у класі.

Мікрофон реагує на гучність, а не розпізнає грім. Цей пристрій не є системою попередження про небезпеку.

Спочатку спробуй самостійно. Відкривай лише потрібну підказку.

1. З чого почати?

Збережи копію. Заміни подію B подією гучного звуку в MakeCode для V2.

2. Яка умова потрібна?

Збережи if active; після розрахунку задай active = false. Мікрофон не має запускати відлік сам.

3. Як перевірити?

Звук до A — без результату; перший після A — результат; повторний — без змін. Для точного обчислення окремо підстав 3000 мс.

Навчайся з ШІ: перевір одиниці та стани

Попроси ШІ знайти помилку в обчисленні distance = elapsed * 343, якщо elapsed у мілісекундах. Після пояснення сам перевір виправлення на 3000 мс.

ШІ може галюцинувати: переплутати одиниці, назви команд або назвати певну відстань «безпечною». Звір API свого редактора й перевір числові приклади. Калькулятор не визначає безпеку під час грози.

Підказка: що таке промпт?

Промпт — запит до ШІ. Назви редактор, одиниці змінних, очікувану поведінку й свою помилку. Попроси пояснення та тести. Не додавай особисті дані.

Генератор промпту · сформулюй власне запитання

Кнопка лише складає текст. Відповідь ШІ тут не генерується; скопіюй запит у дозволений учителем інструмент.
