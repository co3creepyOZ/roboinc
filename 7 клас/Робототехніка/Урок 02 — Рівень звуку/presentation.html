1

Рівень звуку

Звук

Коливання доходять до мікрофона.

Датчик

micro:bit V2 перетворює їх на сигнал.

Програма

Отримує число 0–255 та обирає дію.

01

Шкала 0–255 — не децибели

100

Не означає 100 дБА.

200 проти 100

Не доводить удвічі більшу гучність.

Наш індикатор

Не оцінює безпеку слуху чи відповідність нормам.

02

Порівнюй за однакових умов

Потрібна V2

На V1 немає вбудованого мікрофона.

На сторінці

Модель отримує число вручну, не слухає тебе.

На платі

Залиш сталими відстань та орієнтацію. Достатньо звичайної розмови.

06

Послідовність показів важливіша за один

Зліва — раніші записи, справа — новіші.

Точні значення: 0 → 60 → 101 → 255 → 60. Це не дБ.

07

Сплеск і тривалий рівень

Один високий стовпчик

Окреме спостереження.

Багато підряд

Потрібна послідовність для порівняння.

Точні числа

Читай у таблиці, не лише за висотою.

08

Алгоритм рішення

Опис словами, не код для вставлення.

ПОСТІЙНО
  рівень ← мікрофон
  якщо рівень > 100
  показати хрестик
  інакше: галочку
  чекати 100 мс
09

Побудуй дві версії

  1. 01

    Спочатку показуй число або plot bar graph до 255.

  2. 02

    Потім додай рішення за порогом 100.

  3. 03

    Порівняй повну форму з короткою без else.

10

Залиш доказ досліду

  1. 01

    Передбач 99/100/101.

  2. 02

    Запиши 0,60,101,255,60.

  3. 03

    Зміни лише поріг, поясни новий значок.

Знайди блоки MakeCode

Довідка до практики · 1

Input / Вхідні дані

Рівень звуку / sound level
Показник 0–255; на фізичному пристрої потрібна V2. Запиши у змінну «рівень».

Basic / Основні

Показати число / show number
Показує значення змінної «рівень».

LED / Світлодіоди

Побудувати стовпчикову діаграму / plot bar graph
Значення — «рівень», верхня межа — 255. Це окремий варіант від показу іконок.

Довідка до практики · 2

Basic / Основні

Постійно / forever
Повторює зчитування датчика та перевірку умови.

Variables / Змінні

Задати … значення / set … to; значення змінної
Натисни «Створити змінну / Make a Variable». Блок set змінює значення, овальний блок із назвою читає його.

Logic / Логіка

Якщо…то…інакше / if…then…else
Обирає дію за умовою. Додай гілку «інакше» кнопкою + на блоці, якщо її немає.
