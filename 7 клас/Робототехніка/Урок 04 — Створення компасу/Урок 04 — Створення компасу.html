Тема уроку

Проєкт «Створення компасу»

Досліди сторони світу, прочитай першу програму Python і навчися перевіряти поради ШІ.

Твоя місія

Ти визначатимеш напрямок за кутом, поясниш змінні, розгалуження й цикли Python та перевіриш граничні значення програми.

Основний маршрут — близько 20 хвилин у браузері. Завантаження на плату й озвучення — додатково.

Що таке компас?

Компас допомагає визначати напрямки. Магнітний компас орієнтується за магнітним полем Землі. Електронний компас micro:bit використовує магнітометр.

Магнітна північ може відрізнятися від географічної. Металеві предмети й магніти поблизу спотворюють показники.

N — North

Північ: 0° (або 360°).

E — East

Схід: 90°.

S / W

Південь — South: 180°. Захід — West: 270°.

Калібрування

Перед вимірюванням виконай калібрування за підказками плати: повільно нахиляй і повертай її, заповнюючи світлодіодний малюнок. До завершення калібрування програма очікує.

Працюй подалі від магнітів і металевого столу, в умовах майбутнього використання. Після калібрування тримай плату приблизно горизонтально.

02 / Теорія · 3 хв

Python і MicroPython

Що таке Python?

Python — текстова мова програмування. Програміст записує команди за певними правилами, а спеціальна програма — інтерпретатор — виконує код. Зрозумілі назви та відступи допомагають читати програму.

Мову можна використовувати для обчислень, обробки даних і автоматизації повторюваних завдань. Програма може зберігати дані у змінних, обирати дії за умовою та повторювати команди в циклах.

Що таке MicroPython?

MicroPython — реалізація Python для невеликих пристроїв із обмеженими ресурсами. На micro:bit вона дає змогу керувати світлодіодами та працювати з кнопками й датчиками.

Знайомі правила Python залишаються: змінні, умови, цикли й відступи. Для роботи з платою використовують спеціальні модулі, зокрема microbit. Не всі бібліотеки та можливості Python для комп’ютера доступні на платі.

Мова, редактор і плата — різні речі

  • Мова визначає, як записувати команди.
  • Редактор — місце, де ти пишеш і змінюєш код.
  • Micro:bit — пристрій, на якому працює завантажена програма.

У цьому уроці пишемо MicroPython у Python Editor micro:bit ↗. Python-режим MakeCode ↗ має інші команди для плати: приклади MicroPython не можна переносити туди без змін.

Як це працює в нашому компасі?

Програма отримує кут від датчика → зберігає його у змінній → обирає літеру за умовою → показує її на екрані. Цикл повторює ці дії, щоб напрямок оновлювався.

У розділі «Дослідження» розбери запис цих команд. У «Майстерні» перевір модель і створи програму.

03 / Дослідження

Читай код як послідовність дій

Для плати використовуємо MicroPython у Python Editor micro:bit. Його команди відрізняються від Python-режиму MakeCode. Наведений код призначений для python.microbit.org.

Змінні та значення

heading = 90
direction = "E"
ready = True

Змінна має ім’я й зберігає значення: число, текст у лапках або логічне True / False. Знак = задає значення; == порівнює. Імена heading і Heading різні.

Розгалуження

if heading < 45:
    direction = "N"
else:
    direction = "інший напрямок"

if — якщо; elif — інакше якщо; else — інакше. У ланцюжку виконується перша відповідна гілка. Після заголовка — двокрапка, вкладені команди мають відступ (зазвичай 4 пробіли).

Логічні операції

and — І, or — АБО, not — НЕ. Для півночі потрібне АБО: кут менший за 45 або не менший за 315.

Цикли

for i in range(3):
    print(i)

Це звичайний приклад Python: виведе 0, 1, 2 в консоль — три повторення. Кінцеве число 3 не входить у range(3).

while True:
    heading = compass.heading()
    sleep(200)

while True повторює команди, доки працює програма. На micro:bit sleep(200) — пауза 200 мс. Зчитування має бути всередині циклу, щоб реагувати на поворот.

# починає коментар. from … import … підключає потрібні команди. Дужки у compass.heading() означають виклик функції.

Сплануй перевірку програми

Передбач → перевір → поясни

  1. Визнач, які дані отримує програма та яке правило вона перевіряє.
  2. Обери кілька значень: звичайне, на межі умови та по обидва боки від неї.
  3. Запиши очікуваний результат до запуску програми.
  4. У «Майстерні» перевір припущення в інтерактивній моделі, потім створи програму в редакторі.
  5. Порівняй результати. Якщо вони різні, перевір умову, порядок команд і вхідні дані.

Модель на сторінці допомагає дослідити правило. Роботу датчика перевіряй окремо на платі за вказівками уроку.

Алгоритм псевдомовою

Це опис кроків звичайними словами, а не готовий код для редактора. ← означає «записати значення». Відступи показують вкладені дії; «КІНЕЦЬ ПОВТОРЕННЯ» закриває запис циклу, але ПОСТІЙНО запускає його знову.

Як читати цей код

Читай код згори вниз. Рядки після # — коментарі для людини, вони не виконуються. Двокрапка : відкриває блок команд. Відступ у чотири пробіли показує, що команда належить умові, циклу чи функції. Коли відступ зменшується, вкладений блок закінчується.

= записує значення, а == порівнює на рівність. У Python десяткову частину пишуть через крапку: 18.5. Слова й повідомлення беруть у лапки.

Спочатку виконується input.calibrate_compass(). Запис def on_forever(): визначає функцію, але не запускає її тіло одразу. Команда basic.forever(on_forever) доручає MakeCode викликати її знову й знову.

Змінні та три типи значень

heading — число: кут у градусах. direction — рядок: "N", "E", "S" або "W". Наприклад, direction = "E" зберігає текст, а не назву іншої змінної.

Порівняння heading < 45 дає логічне значення True або False. У цьому прикладі воно використовується одразу в умові, без окремої логічної змінної. Отже, тут працюємо з числом, рядком і логічним результатом.

Область видимості змінних

heading і direction створюються всередині on_forever та використовуються в цій функції. Для цього прикладу достатньо локальних змінних: інші функції їх не змінюють, тому global не потрібне.

Гілки if/elif/else не створюють окремої області видимості. Тому direction, задана в обраній гілці, доступна в basic.show_string(direction) нижче. Кожна гілка обов’язково задає direction.

Розгалуження: чому для півночі or

За кута 350 перевірка heading < 45 хибна, але heading >= 315 істинна. or означає «АБО»: достатньо однієї істинної частини. Тому обираємо N.

За кута 90 перша умова хибна, а heading < 135 істинна: обираємо E. Після першої істинної гілки решту пропускаємо. else охоплює кути від 225 до 314.

Повторення та перевірка

basic.forever забезпечує повторення. У кожному проході зчитуємо новий кут, визначаємо літеру, показуємо її та чекаємо 200 мс. % 360 — остача від ділення: 360 перетвориться на 0. Калібрування стоїть поза повторенням.

Простеж 44 → 45 → 315: очікуємо N → E → N. Якби зчитування стояло тільки перед повторенням, поворот плати не оновлював би heading.

Приклад MakeCode Python · розгорни код
# Калібруємо компас перед повторними вимірюваннями
input.calibrate_compass()
def on_forever():
    heading = input.compass_heading() % 360
    if heading < 45 or heading >= 315:
        direction = "N"
    elif heading < 135:
        direction = "E"
    elif heading < 225:
        direction = "S"
    else:
        direction = "W"
    basic.show_string(direction)
    basic.pause(200)
basic.forever(on_forever)

Перевір роботу

Перевір 0, 44 → N; 45, 134 → E; 135, 224 → S; 225, 314 → W; 315, 359 → N.

Для точного тесту підстав число замість зчитування датчика, потім поверни справжнє зчитування. Якщо потрібного датчика немає в симуляторі, виконай перевірку з підставленими значеннями або на відповідній платі.

Для тестів тимчасово замінюй зчитування кута заданими числами. Поясни, чому and замість or руйнує визначення півночі. Поверни датчик після тестів.

Змінні та типи даних

heading містить число — кут 0…359 після операції % 360. direction містить рядок з однією літерою, наприклад "N". Вираз heading < 45 повертає логічне значення True або False.

display.show(direction) показує текст зі змінної. Лапки потрібні в direction = "N", але не навколо direction у виклику display.show.

Область видимості змінних

У цьому прикладі немає власних функцій. heading і direction задаються на верхньому рівні програми всередині циклу. Самі while та if не створюють нової області видимості.

У кожному проході heading оновлюється. Одна з гілок задає direction, після чого команда показу читає її. global тут не потрібне: ми не змінюємо ці змінні з тіла власної функції.

Розгалуження: if, elif, else

if перевіряє перший варіант, elif — наступний, лише якщо попередні хибні, а else охоплює решту. Для півночі потрібне or: кут або менший за 45, або не менший за 315.

За heading = 135 північ і схід не підходять; умова heading < 225 істинна, тому direction стає "S".

Цикл while True

True — логічне «істина». Тому while True: повторюється, поки працює програма. Команди з відступом — один прохід: зчитати кут → обрати напрямок → показати → зачекати.

sleep(200) задає паузу 200 мс. Калібрування не повторюється, бо записане перед циклом. Перевір 0 та 359: в обох випадках очікуємо N.

Приклад MicroPython · розгорни код
from microbit import compass, display, sleep

# Калібруємо один раз перед циклом
compass.calibrate()
while True:
    heading = compass.heading() % 360
    if heading < 45 or heading >= 315:
        direction = "N"
    elif heading < 135:
        direction = "E"
    elif heading < 225:
        direction = "S"
    else:
        direction = "W"
    display.show(direction)
    sleep(200)

Перевір роботу

Перевір 0, 44 → N; 45, 134 → E; 135, 224 → S; 225, 314 → W; 315, 359 → N.

Для точного тесту підстав число замість зчитування датчика, потім поверни справжнє зчитування. Якщо потрібного датчика немає в симуляторі, виконай перевірку з підставленими значеннями або на відповідній платі.

Твоє завдання

Для тестів тимчасово замінюй зчитування кута заданими числами. Поясни, чому and замість or руйнує визначення півночі. Поверни датчик після тестів.

У висновку для Classroom зазнач середовище, тестові значення та очікувані й отримані результати.

Створи програму в редакторі

Компас із голосом

У MicroPython є модуль speech. Для V2 з вбудованим динаміком можна додати import speech і виклики speech.say("north"), "east", "south", "west". Використовуй англійські назви. Спочатку перевір базову програму, потім додавай озвучення лише при зміні напрямку, щоб слова не повторювалися безперервно.

Звуковий вихід може доповнити доступність, але його зручність потрібно перевірити з користувачем; він не гарантує придатності для самостійної навігації.

Дослідження з ШІ

Попроси дозволений учителем сервіс пояснити принцип саморобного магнітного компаса. Перевір запропоновані матеріали й спосіб із учителем до виготовлення. Не сприймай відповідь ШІ як готову перевірену інструкцію.

Компас майбутнього

Опиши або намалюй компас майбутнього. За правилами вчителя можна використати генератор зображень. Збережи промт і поясни, які функції реалістичні, а які вигадані.

Навчання з ШІ

Делегування

Попроси підказку, а напрямки для тестових кутів передбач сам.

Опис

Укажи MicroPython, редактор, межі секторів і бажаний формат.

Оцінка

Перевір команди, відступи та граничні кути.

Відповідальність

Поясни програму своїми словами й зазнач допомогу ШІ.

Що таке промпт і як його скласти?

Промпт — запит або інструкція для ШІ. Укажи контекст (тема й середовище), мету (що хочеш зрозуміти), деталі (умова, твоя спроба, очікуваний результат) і формат відповіді.

Приклад: «Я учень 7 класу, виконую цей проєкт. Поясни, чому мій результат відрізняється від очікуваного. Ось умова й моя спроба: … . Дай одну підказку й тест для перевірки, а не готову відповідь». Заміни крапки власними відомостями та вкажи редактор.

Скористайся генератором нижче, прочитай готовий текст і за потреби уточни його. Він не надсилає запит автоматично. Відповідь ШІ перевір самостійно; не додавай особистих даних.

Генератор промптів · склади власний запит

Тут ти автор запиту. Пиши своїми словами: вибирати готову мету не потрібно. Заповни лише потрібні поля; обов’язково вкажи, у чому потрібна допомога. Назви своє середовище: блоки MakeCode, MakeCode Python або MicroPython, якщо воно використовується у цьому завданні.

Кнопка лише поєднує написані тобою частини. Тут немає відповіді ШІ, і текст нікуди автоматично не надсилається. Перечитай запит перед копіюванням. Не додавай особистих даних.

Готовий приклад промпту до цього уроку

Цей приклад підготовлено заздалегідь — це не відповідь ШІ. Можеш скопіювати його або натиснути «Взяти за основу»: тоді поля конструктора заповняться прикладом, а ти зміниш їх під свою спробу. Ця кнопка замінить поточний текст у полях.

Скористайся дозволеним учителем сервісом. Попроси підказку, а потім перевір відповідь власними тестами. Якщо сервісу немає, обговори запит із учителем або однокласником.

ШІ може галюцинувати:

ШІ може вигадати команду, змішати MakeCode Python із MicroPython або пропустити відступ. Впевнений текст не доводить правильність.

  1. Звір API з довідкою MicroPython.
  2. Перевір синтаксис: двокрапки, лапки, відступи, = та ==.
  3. Випробуй межі 45, 135, 225 і 315 та значення поруч.
  4. Перевір 0 і 359: обидва мають дати N.
  5. Поверни плату: показник має оновлюватися. Виправ помилки й повтори тести.
