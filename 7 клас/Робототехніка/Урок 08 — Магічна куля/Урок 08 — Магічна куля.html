1 / Знайомство

Магічна куля

Тема уроку

Гра «Магічна куля». Створи пристрій, який після струшування випадково показує «так», «ні» або «можливо». Навчися перевіряти кожну гілку програми.

18–20 хвилин: знайомство й теорія — 4 хв, дослідження — 3 хв, один варіант програмування — 7 хв, робота з ШІ — 2 хв, квіз і висновок — 3–4 хв. Інші редактори та розширення — за бажанням.

Передбач результат

Куля тричі відповіла «так». Чи зобов’язана наступного разу відповісти «ні»?

Безпечна робота

Струшуй плату обережно, тримай її міцно та не натягуй кабель. Можна працювати лише в симуляторі. «Магічна куля» — гра з випадковими відповідями, а не порадник для важливих рішень.

2 / Теорія

Випадковість і розгалуження

Як працює «магія»

У знайомій іграшці після перевертання у віконці з’являється одна з готових відповідей. У нашій моделі замість механізму працює програма: акселерометр розпізнає струшування, генератор обирає число, а світлодіоди показують символ.

Програма не розуміє запитання і не знає майбутнього. Її відповідь залежить від випадкового числа.

Одне число — одна відповідь

numberСимволЗначення
1?Можливо / не знаю
2×Ні
3✓Так

Змінна number зберігає отримане число. Розгалуження перевіряє його та обирає одну дію. Межі 1 і 3 включені до діапазону. Повтори можливі: три спроби не гарантують трьох різних відповідей.

Від блоків до Python

Python — текстова мова програмування. У MakeCode Python доступні команди MakeCode, а у MicroPython — команди бібліотеки micro:bit. Логіка однакова, назви команд відрізняються.

number = 3 записує число; number == 3 перевіряє рівність і дає True або False. Двокрапка та відступ позначають початок і вміст гілки.

3 / Дослідження

Прочитай та перевір алгоритм

Прочитай алгоритм

1. Після струшування вибрати число. Якщо 3, показати так; інакше якщо 2, показати ні; інакше показати знак питання.

Почни з події «Струшування». У ромбі обери гілку «Так» або «Ні» за результатом перевірки. Зістав кроки схеми з умовою завдання: Очистити екран; number ← випадково 1…3; number = 3?; number = 2?; Показати ✓; Показати ×.

Як читати блок-схему
  • Овал — початок або кінець.
  • Прямокутник — дія, обчислення або пауза.
  • Паралелограм — введення чи виведення даних.
  • Ромб — перевірка умови з виходами «Так» / «Ні».
  • Стрілки задають порядок; стрілка назад означає повторення.

Кінець обробки події не означає завершення всієї програми.

Алгоритм псевдомовою

Це опис кроків звичайними словами, а не готовий код для редактора. Відступи показують вкладені дії. ← означає «записати значення».

Прочитай приклад псевдомовою
КОЛИ плату струсили
    ОЧИСТИТИ екран
    number ← випадкове ціле від 1 до 3
    ЯКЩО number = 3 ТО
        ПОКАЗАТИ ✓
    ІНАКШЕ ЯКЩО number = 2 ТО
        ПОКАЗАТИ ×
    ІНАКШЕ
        ПОКАЗАТИ ?
    КІНЕЦЬ ЯКЩО
КІНЕЦЬ ОБРОБКИ ЖЕСТУ

Прочитай разом зі схемою: кожне «ЯКЩО» відповідає ромбу, «ПОКАЗАТИ» — паралелограму. Відступи показують, яка дія належить до гілки.

Простеж виконання: number = 1 — обидві перевірки хибні, тому виконується «ІНАКШЕ» й з’являється ?.

Пройди гілками

Випало число 1. Перша умова number = 3 хибна. Друга number = 2 теж хибна. Що виконається?

Про цю гру

Налаштуй алгоритм на схемі та перевір усі тестові показники. Гра є навчальною моделлю: вона не читає датчики плати.

4 / Майстерня

Майстерня

Інтерактивне дослідження

Уяви жартівливе запитання, на яке можна відповісти «так» або «ні». Натисни «Струсити». Кнопки тестів примусово задають число — вони потрібні для перевірки, а не випадкового вибору.

Струсни кулю.

Дослід: перевір 1, 2, 3; потім зроби п’ять випадкових спроб. Чи були повтори? Відсутність певного результату в п’яти спробах ще не доводить помилку.

MakeCode · блоки

Для короткого уроку обери один редактор. Усі три варіанти мають однакову поведінку.

Мета: одне струшування дає одну відповідь. Перевірка: 1 → ?, 2 → ×, 3 → ✓; без нового жесту відповідь зберігається.

  1. Відкрий MakeCode, створи проєкт «Магічна куля».
  2. У події «на струшування» очисти екран і задай number випадкове число від 1 до 3.
  3. Додай «якщо number = 3» — показати галочку; «інакше якщо number = 2» — хрестик; «інакше» — знак питання.
  4. Для перевірки по черзі підстав числа 1, 2, 3 замість випадкового вибору. Після перевірки поверни випадковий блок.
1. З чого почати?

Створи одну змінну number. Подія струшування запускає весь вибір; не розміщуй його у «постійно».

2. Які блоки допоможуть?

Потрібні подія, запис у змінну, випадкове число, порівняння та показ іконки. У розгалуженні додай гілку «інакше якщо» й кінцеве «інакше».

3. Як перевірити?

Підстав 3: галочка. 2: хрестик. 1: питання. Якщо малюнок неправильний, перевір вкладеність іконок. Випадкове число обирається лише один раз перед умовами.

MakeCode Python

Відкрити редактор. Завдання: відтвори логіку, перевір усі три значення; зміни зображення для відповіді «можливо» та переконайся, що «так» і «ні» лишилися без змін.

Приклад коду · після власної спроби
# Одна відповідь після одного струшування
def on_gesture_shake():
    basic.clear_screen()
    number = randint(1, 3)
    if number == 3:
        basic.show_icon(IconNames.YES)
    elif number == 2:
        basic.show_icon(IconNames.NO)
    else:
        basic.show_icon(IconNames.QUESTION_MARK)

input.on_gesture(Gesture.SHAKE, on_gesture_shake)
1. Як читати код і почати роботу?

Перемкни MakeCode на Python. def описує обробник, а останній рядок під’єднує його до жесту. Команди з відступом виконуються після струшування.

def on_gesture_shake():
    number = randint(1, 3)

Це фрагмент для пояснення; повний приклад розгорни вище.

2. Змінні, типи та область видимості
number = 3  # Ціле число
number == 3  # Логічний результат: True або False

number — локальна змінна обробника: поза ним ми її не використовуємо, global не потрібен.

Число зберігає вибір; логічне значення визначає гілку. Рядок — текст у лапках. Ідентифікатор number пишемо без лапок.

3. Умови, повторення та перевірка
if number == 3:
    # Тут відповідь «так»
    pass
elif number == 2:
    # Тут відповідь «ні»
    pass
else:
    # Тут відповідь «можливо»
    pass

Схема вище показує вкладеність: pass — порожня дія-заповнювач; у повній програмі на цьому місці показ іконки. Працює лише одна гілка. Остання відповідає числу 1, бо діапазон обмежено 1…3.

Повторні запуски забезпечує подія. Окремий while не потрібен.

Замінюй отримання випадкового числа константами 1, 2, 3, перевір і поверни генератор. Команди двох редакторів не змішуй.

MicroPython

Відкрити редактор. Завдання: відтвори логіку, перевір усі три значення; зміни зображення для відповіді «можливо» та переконайся, що «так» і «ні» лишилися без змін.

Приклад коду · після власної спроби
from microbit import *
import random

# Перевіряємо жест, поки програма працює
while True:
    if accelerometer.was_gesture("shake"):
        display.clear()
        number = random.randint(1, 3)
        if number == 3:
            display.show(Image.YES)
        elif number == 2:
            display.show(Image.NO)
        else:
            # Власне зображення знака питання
            display.show(Image("09990:90009:00990:00000:00900"))
    sleep(50)  # Пауза є навіть без струшування
1. Як читати код і почати роботу?

Відкрий Python Editor. Імпорти дають доступ до плати й випадкових чисел. Цикл перевіряє жест; вибір виконується лише після нього.

while True:
    if accelerometer.was_gesture("shake"):
        number = random.randint(1, 3)

Це фрагмент для пояснення; повний приклад розгорни вище.

2. Змінні, типи та область видимості
number = 3  # Ціле число
number == 3  # Логічний результат: True або False

number створюється на рівні програми після першого жесту. if і while не утворюють окремої області видимості. До першого жесту значення не читаємо. Рядок "shake" — текстова назва жесту, рядок із цифрами — зображення.

Число зберігає вибір; логічне значення визначає гілку. Рядок — текст у лапках. Ідентифікатор number пишемо без лапок.

3. Умови, повторення та перевірка
if number == 3:
    # Тут відповідь «так»
    pass
elif number == 2:
    # Тут відповідь «ні»
    pass
else:
    # Тут відповідь «можливо»
    pass

Схема вище показує вкладеність: pass — порожня дія-заповнювач; у повній програмі на цьому місці показ іконки. Працює лише одна гілка. Остання відповідає числу 1, бо діапазон обмежено 1…3.

while True повторює перевірку. sleep(50) має відступ циклу, але стоїть поза if, тому пауза є навіть без жесту.

Замінюй отримання випадкового числа константами 1, 2, 3, перевір і поверни генератор. Команди двох редакторів не змішуй.

Додатково · за бажанням

Продовж дослідження

Коротке ТЗ «Різні характери»

Мета: додати до кулі дві передбачувані відповіді та зберегти випадковий вибір.

Засоби: готова програма, події кнопок A і B, блоки показу іконок.

Як має працювати програма

  • Кнопка A — показати ✓ («так»).
  • Кнопка B — показати × («ні»).
  • Струшування — обрати число 1–3 й показати відповідну іконку.

Кнопки одразу показують відповідь. Вони не змінюють правила наступного струшування.

Перевір результат

  1. Натисни A, потім B: має з’явитися галочка, потім хрестик.
  2. Перевір гілки струшування з числами 1, 2, 3: ?, ×, ✓.
  3. Поверни випадковий вибір і переконайся, що кнопки працюють після струшування.
Створи програму в редакторі

Продовження для micro:bit V2

Завдання: досліди запуск за гучним звуком. Датчик помічає гучність, а не зміст слів.

Підказка: якщо відповідь має з’являтися після тиші, потрібна окрема подія або перевірка тихого звуку. Одна подія гучного звуку цього не забезпечує.

Перевір: тихе приміщення не запускає нову відповідь; після гучного звуку та переходу до тиші з’являється одна відповідь.

Підказка: як виконати завдання. Спочатку спробуй самостійно. Відкривай лише потрібний крок; підказки не знижують оцінку.

1. З чого почати?

Збережи копію основного проєкту. Прочитай умову вище й визнач, яку одну дію змінюєш. Завдання: досліди запуск за гучним звуком. Датчик помічає гучність, а не зміст слів.

2. Які блоки допоможуть?

Використай потрібні для цієї зміни засоби з довідки: На струшування / on shake — Вхідні дані / Input; Задати number значення / set number to — Змінні / Variables; Вибрати випадково від…до / pick random — Математика / Math; Якщо…то…інакше; дорівнює / if…then…else; equals — Логіка / Logic. Повну таблицю блоків розміщено перед додатковими завданнями.

3. Як перевірити?

Перевір тишу, гучний звук і повернення до тиші. Одна подія гучного звуку сама по собі не очікує тиші.

Навчайся з ШІ

Попроси ШІ допомогти перевірити логіку, а не лише написати програму. Обери одну його пораду та перевір її в редакторі на числах 1, 2 і 3.

ШІ може галюцинувати: вигадати команду чи переплутати редактори. Впевнене пояснення може бути хибним. Звір команди й перевір результат запуском.

Підказка: що таке промпт?

Промпт — запит до ШІ. Назви редактор, очікувану поведінку та свою складність. Попроси коротку підказку й тести. Не додавай особисті дані.

Генератор промпту · сформулюй власне запитання

Заповни поля своїми словами. Кнопка лише складає текст: ШІ тут не запускається. Скопіюй запит у дозволений учителем інструмент.
